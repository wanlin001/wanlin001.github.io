{% comment %} Visitor counting. Only runs on the published site (JEKYLL_ENV=production, which is what GitHub Pages uses) — local `jekyll serve` previews are never counted. Set ONE of these in _config.yml under `analytics:` and leave the other blank. goatcounter_code the subdomain part of your GoatCounter site, e.g. "wanlin" for https://wanlin.goatcounter.com cloudflare_token the token from Cloudflare Web Analytics Both are cookie-free and do not need a consent banner. The dashboard is private to your own account either way. {% endcomment %} {% if jekyll.environment == "production" %} {% if site.analytics.goatcounter_code and site.analytics.goatcounter_code != "" %} {% endif %} {% if site.analytics.cloudflare_token and site.analytics.cloudflare_token != "" %} {% endif %} {% endif %}
